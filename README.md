# SE Connect

Private member-network frontend for SE Connect.

Features include authenticated member discovery, editable member profiles, member-to-member direct messaging, and an administrator console for access control and aggregate reporting.

The visual theme uses an Instagram-inspired colourful interface with saffron, white, green and Ashoka-blue accents.

## Production

This build has `DEMO_MODE` disabled and contains no embedded member directory or passwords. See `DEPLOY.md` for Supabase and GitHub Pages setup.
